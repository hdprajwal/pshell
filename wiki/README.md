# pshell wiki

pshell stands for "personal shell". It is a desktop shell for Hyprland, built on [Quickshell](https://quickshell.org): a bar, panels, notifications, a lockscreen, wallpaper and theming, all in one process.

A bar widget is either a program that prints a line, or a QML file. pshell also runs bar widgets made for Omarchy, without changes. There is no daemon to install or keep running.
